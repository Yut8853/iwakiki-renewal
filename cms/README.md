## 記事本文への画像挿入

記事の新規作成・編集画面で、本文の画像を入れたい位置をクリックし「＋ 本文に画像を追加」を選択します。
公開画像のURL（https:// または http://）と代替テキストを入力し、「画像を確認」でプレビューしてから「本文に挿入」を押します。
複数枚を文章の間に入れられます。最後に記事を「保存」してください。

画像は本文に Markdown の `![説明](<画像URL>)` として保存されます。この行を移動・削除すると、画像の位置変更・削除ができます。
一覧・記事上部のアイキャッチ画像とは別です。現在の入力方式は公開URLの指定で、ファイルのアップロードではありません。
